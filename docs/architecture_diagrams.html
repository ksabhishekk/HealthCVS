System Architecture & the 7‑Transaction Audit Trail

Two figures for the project report and presentation slides: how the pieces talk to each other, and what happens to a single claim from submission to settlement. Export directly from this page for slides — the diagrams are vector, so they scale cleanly.

FIG. 1

System Architecture

Two independent portals write to a shared set of smart contracts. Neither portal trusts the other's server — they only trust what's on-chain. The Oracle Worker is the one component that bridges the deterministic blockchain world and the probabilistic AI world.

FIG. 2

The 7-Transaction Audit Trail

What happens to one claim, in order. TX4 is not a single model's opinion — it's a weighted ensemble of three independent signals, with two override floors that can push a claim toward manual review regardless of what the ensemble alone would say.
